# Data Directory

This directory stores URL datasets used for training and evaluation.

## Files

- `synthetic_urls.csv` — Generated by `scripts/generate_synthetic.py` (10k URLs)
- `phishtank_urls.csv` — Downloaded by `scripts/download_datasets.py` (requires API key)
- `iscx_urls.csv` — ISCX-URL-2016 dataset (download manually from UNB)

## Columns

All CSV files follow this schema:

| Column | Type | Description |
|--------|------|-------------|
| url | string | The full URL |
| label | int | 0=benign, 1=phishing, 2=malware, 3=defacement |
| source | string | Dataset origin identifier |

## Obtaining Real Datasets

### PhishTank
1. Register at https://www.phishtank.com/developer_info.php
2. Get API key
3. Set `PHISHTANK_API_KEY=<key>` in `.env`
4. Run `malurlguard download --source phishtank`

### ISCX-URL-2016
1. Request access at https://www.unb.ca/cic/datasets/url-2016.html
2. Download the CSV files
3. Place in `data/iscx_urls.csv`

### Majestic Million (benign baseline)
- Available at https://majestic.com/reports/majestic-million
- Top 1M websites, used as benign samples
